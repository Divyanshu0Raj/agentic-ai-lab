# Agentic AI Lab

A hands-on collection of AI and agentic AI projects, built to explore practical applications of LLMs, tools, retrieval, and automation.

## Projects

| Project | Description | Stack |
|---|---|---|
| [Small Business Voice Agent](./01-small-business-voice-agent/) | A product assistant that answers catalogue questions and checks stock through an MCP tool. | Python, Groq, FastMCP, Streamlit |

## Goals

- Build practical AI projects from end to end.
- Learn how LLM applications connect to tools and data.
- Keep projects understandable, testable, and reproducible.
- Document architecture, design decisions, limitations, and setup.

## Getting Started

Each project has its own README with setup instructions, dependencies, and usage.

## Security

API keys, `.env` files, virtual environments, caches, and logs should never be committed. Use each deployment platform's secrets manager for production credentials.
