# Small Business Voice Agent

A practical AI voice assistant for small businesses.

## Planned Features

- Voice input and speech recognition
- LLM-powered responses using Groq
- Cloud text-to-speech
- Retrieval-Augmented Generation (RAG)
- Model Context Protocol (MCP) tools
- Latency logging and automated tests

## Project Status

Phase 1: Project setup and foundational voice pipeline.

## Technology Stack

- Python
- Groq API
- Cloud speech services
- SQLite and FAISS
- MCP
- pytest

## Security

API keys must be stored in environment variables and must never be committed to Git.
